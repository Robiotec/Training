GUIA RAPIDA - split_dataset.py

Script:
- scripts/data/split_dataset.py

Que hace:
- Toma un dataset base con estructura YOLO (images/labels).
- Genera train/val/test en data/splits.
- Crea data.yaml en cada dataset generado.
- Actualiza configs/caja.yaml, configs/vetas.yaml y/o configs/mixto.yaml (salvo que uses --no-update-training-configs).

Comandos cortos (uv run):

1) Caso por defecto (solo vetas)
uv run scripts/data/split_dataset.py
Que hace:
- Usa los defaults del script.
- Genera modo solo_vetas.
- Escribe salida en data/splits y actualiza configs/vetas.yaml.

2) Solo cajas y mixto
uv run scripts/data/split_dataset.py --modes solo_cajas mixto
Que hace:
- Genera dos datasets en una sola corrida:
  - solo_cajas (1 clase)
  - mixto (2 clases)
- Actualiza configs/caja.yaml y configs/mixto.yaml.

3) No tocar YAMLs de training
uv run scripts/data/split_dataset.py --no-update-training-configs
Que hace:
- Genera el/los split(s), pero NO modifica configs/*.yaml.

4) Cambiar base de entrada
uv run scripts/data/split_dataset.py --base-dir data/curated/limpieza_caja
Que hace:
- Usa otra carpeta fuente para construir los splits.

5) Cambiar version/prefijo de salida
uv run scripts/data/split_dataset.py --dataset-prefix 2026-03-07
Que hace:
- Nombra carpetas de salida con ese prefijo (versionado).

Salidas:
- data/splits/<prefix>_solo_cajas_v1/
- data/splits/<prefix>_solo_vetas_v1/
- data/splits/<prefix>_mixto_v1/
- data/splits/<prefix>_split_summary_global.txt

Notas utiles:
- Split fijo: 80% train, 10% val, 10% test.
- Seed fija: 42.
- Si la carpeta de salida existe, se reemplaza.
